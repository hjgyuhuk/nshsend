# Anti-patterns
- ❌ Detecting UI state by matching a translated substring (e.g. `statusMessage().includes("PIN")`) — the check silently breaks when the interface language changes — expose an explicit boolean signal from the store (`sendPinRequired`) and branch on that.
- ❌ Uploading multiple files to a LocalSend peer over concurrent connections — LocalSend on iOS (v1.19.0) resets the additional upload connection (`connection reset by peer` ~14ms in, likely a drop with unread request data), which also cancels the in-flight sibling upload — upload sequentially over the single pooled keep-alive connection (`send/session.go`); the protocol permits parallel uploads but does not require it.
- ❌ Assuming `process.spawn` children inherit the desktop session environment — NSH sanitizes the spawned sidecar's env (`DBUS_SESSION_BUS_ADDRESS` and `XDG_RUNTIME_DIR` are stripped) — resolve the session bus with the standard fallback `unix:path=/run/user/<uid>/bus` when the env vars are absent.
- ❌ Driving xdg-desktop-portal FileChooser with short-lived CLI callers (`gdbus call` / `busctl call`) — the portal sends `Request.Close` to the backend as soon as the calling D-Bus connection disconnects, so the dialog dies before the user can answer; `gdbus monitor` additionally never sees `Request.Response` because the signal is addressed to the calling connection — keep one D-Bus connection alive across the OpenFile call and the Response signal (minimal stdlib client in `desktopdialog/dbus.go`).
- ❌ Using `x509.Certificate.CheckSignatureFrom(leaf)` on self-signed LocalSend certs — Go enforces CA `KeyUsageCertSign` constraints and rejects non-CA peer certs — call `leaf.CheckSignature(leaf.SignatureAlgorithm, leaf.RawTBSCertificate, leaf.Signature)` instead.
- ❌ Relying only on `tls.Config.Certificates` without `GetClientCertificate` when dialing LocalSend servers — LocalSend populates `AcceptableCAs` with the server's own DN, causing Go to send an empty client cert list (`remote error: tls: certificate required`) — always set `GetClientCertificate` to return the device cert unconditionally.
- ❌ Writing to an unbuffered `io.Pipe` in Go tests before starting the reader goroutine — blocks forever and hits Go's 10-minute test timeout — start the `bufio.Scanner` reader goroutine first and pass `-timeout 30s`.
- ❌ Putting relative paths with `/` in `nsh.json` `capabilities.process.execute` — rejected by `nsh` capability validation — list bare executable names (`nshsend-core`, `nshsend-core.exe`) resolved via `PATH`.
- ❌ Mocking `process.spawn` via `nsh/test` `modules` stand-ins — `modules` functions cross JSON as Promises and cannot return synchronous `ChildProcess` event emitters — use the `nsh` `host` channel (`host.call` / `host.on`) for test transports.
- ❌ Expecting `onFileDrop` to work on niri/Wayland with the nsh 0.7.0 GTK host — the host rejects the drag at the GTK/Wayland accept stage (`wl_data_offer.accept(serial, nil)` + `set_actions(0,0)` on enter and every motion, no drop event) even though Nautilus offers `text/uri-list` with `source_actions(7)` and niri delivers `enter`/`motion` correctly; the cause is upstream in nsh's GTK `DropTarget` (`file_drop.rs` hardcodes `DragAction::COPY`), not the app's TSX and not the compositor — fall back to the portal file/folder picker buttons.

# Confirmed Patterns
- ✅ Capturing an NSH Linux host's Wayland protocol for DnD debugging: `NSH_VERBOSE=1 WAYLAND_DEBUG=1 nsh run` — `NSH_VERBOSE` is required so the CLI forwards the host's raw stderr (the host's fd1/2 go to a CLI pipe; `WAYLAND_DEBUG` alone never reaches the terminal). Read `wl_data_device.enter/motion`, `wl_data_offer.offer/accept/set_actions` to see whether a drag is accepted; `accept(..., nil)` + `set_actions(0,0)` means the GTK host rejected it. Avoid `pkill -f nsh-linux-host` (matches the calling shell's own cmdline and kills it) — use `pkill -x nsh-linux-host`.
- ✅ Bundling a `process.spawn` sidecar into an NSH Linux AppImage: `nsh package` ships only the TSX app + NSH runtime, so copy the sidecar into the AppDir's `usr/bin/`, insert `export PATH="$HERE/usr/bin:$PATH"` before the `exec` line of `AppRun`, and re-run `appimagetool` — the spawned child inherits the host `PATH` and resolves the bundled binary (no `nsh.json` key ships arbitrary executables).
- ✅ NSH i18n: `locales/app.yml` (`_version: 2`, one key → `{zh-CN, en}`) + `t("key", { param })` called at the display site (reactive to `setLocale`); whole sentences as one key with `%{name}` placeholders; language picker persists the choice in `Storage` and restores it via `setLocale` at startup; wrap `Tray.set` in `effect` so tray labels follow the locale. `nsh test` opens `en-US` by default — pass `locale: "zh-CN"` to assert Chinese text.
- ✅ Theme-following monochrome icons: import a stroke-based `.svg` and recolor it with `<Image style={{ tintColor: token("foreground") }}>` — NSH tints the SVG's opaque pixels on every platform (resvg), so one black-stroke asset serves light/dark and selected states.
- ✅ Tray-resident NSH app: `Application.setQuitMode("explicit")` + controlled `<Window open={shown()} closeOnPress={false} onClosePress={() => shown.set(false)}>` + `Tray.set({ icon, onClick, menu: [{ role: "quit" }] })` — window children stay mounted while hidden, so the sidecar keeps running; windows shown/focused inside tray `onClick`/`onSelect` come to the front (Wayland activation token).
- ✅ Centering an NSH `Dialog` popup on desktop: `m-auto` on the popup's own `class` (see nsh.dev/zh-CN/elements/dialog.md) — the popup and backdrop are sibling layers, so flex-centering `backdropClass` does not position the popup (it lands top-left).
- ✅ Zero-dependency (`CGO_ENABLED=0`) Go sidecar communicating over `stdin`/`stdout` NDJSON keeps networking, mTLS, and streaming file I/O fast and self-contained.
- ✅ Dual transport in `app/src/sidecar/bridge.ts`: `process.spawn` in production and `nsh` `host` transport when `host.params.mockSidecar === true` enables deterministic `nsh test` coverage.
- ✅ Single 200ms retry with `CloseIdleConnections()` on transient `EOF` for idempotent `register` and `prepare-upload` requests only (never stateful `/upload`).
- ✅ Routing `log.SetOutput(diagLog)` to `stderr`, rotating `core.log`, and a 200-line ring buffer keeps `stdout` clean while enabling in-app log inspection via `logs.tail`.

# Decisions & Trade-offs
- Transient store status messages (「发送完成」 etc.) are translated with `t()` at event time and stored as strings — they do not re-translate when the language switches mid-session; acceptable for short-lived notices, avoids storing `{key, params}` structs across every store. Persistent UI labels all call `t()` at render and do follow the locale.
- Go sidecar (`process.spawn`) over `nshm` Rust core or Go `c-archive` + Rust glue — keeps core 100% Go without CGO or Rust toolchain coupling — desktop-only trade-off (mobile would require `c-archive` + thin Rust `nshm`).
- Go-side native file/folder picker + `onFileDrop` (`fileURLToPath`) + `Clipboard.readFiles()` over `Picker.pickFiles` — avoids 512 MiB JS memory copy and streams large files directly from disk.
- `app/tsconfig.json` extends `./.nsh/tsconfig.json` — matches where `nsh` generates `.nsh/` relative to the `entry` directory (`app/`).
